Family Tree & Living Archive: four style directions

“Heirloom Modern”, interpreted four ways. Each tab shows the same family and the same main screen: the tree canvas, a hovered card with its add handles, the voice-memory badge, the mini-map and zoom, and the profile drawer. Drag the canvas to pan, use the zoom buttons, click any card to open it, and press “Replay bloom” to see a new member arrive.

The same in every direction

  • Line meaning never relies on colour alone: solid = birth, broken = adoptive/step, rings = partners, a gap plus a faded line = former partners.
  • Primary action per card is “open profile”; add handles appear on hover or keyboard focus only.
  • New members animate in two beats: the root draws (650 ms, ease-out), then the card blooms (600 ms, slight overshoot). Reduced motion turns this into a 200 ms fade.

How to compare

  • Squint at each canvas: can you still tell the four relationship types apart?
  • Read the drawer bio: this is where people will spend real time.
  • Imagine 200 people: which style still feels calm when zoomed out?

Designer’s pick

Archival Paper as the light theme, with Dark Slate as its dark mode. They share a structure (editorial serif plus one utility face, ink or lamplight roots), so one component set can serve both. Herbarium and Light Table work better as optional “album covers” than as the everyday default.
